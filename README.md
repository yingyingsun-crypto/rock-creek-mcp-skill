# Rock Creek Park — MCP + Skill version

This one-page website is the data-informed comparison for the AI in Design Practice assignment.

- MCP server: `amysatterlee/nps_mcp`
- MCP tools used: `park-list` and `park-details`
- Park code: `rocr`
- Skill used: `sites:sites-building`
- Snapshot date: September 21, 2026

The MCP call supplied the park description, acreage, coordinates, operating hours, address, directions, activities, contact details, and NPS image metadata. Time-sensitive alerts were checked separately against the official NPS conditions page.

See `MCP_AND_SKILL.md` for the process explanation and `evidence/rock-creek-mcp-snapshot.json` for a compact record of the retrieved data.
